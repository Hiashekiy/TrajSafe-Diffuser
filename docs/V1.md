# V1: Occupancy-Conditioned Joint Trajectory–Geometry Diffusion Transformer

按 `docs/联合扩散.md` 重实现的 V1（不兼容旧 z-残差/三阶段/顺序椭圆支路）。

## 网络（`src/models/joint/`）

```
occ [B,1,256,256] → SceneCNN(256→16, ch→128) → 256 map tokens (f_j + φ(q_j))
C_scene = [S, G, M_1..M_256]           S=φ(s)+e_start, G=φ(g)+e_goal
T_k = MLP_P(p_k^t) + ψ(k) + e_traj + w_t φ(p_k^t)
E_k = MLP_E(e_k^t)  + ψ(k) + e_ell  + w_t φ(p_k^t)      w_t = √ā_t
Z = [T_1,E_1,...,T_128,E_128]  → 8×JointBlock(AdaLN + joint self-attn(relative
    bias) + scene cross-attn + FFN)  → 拆回 → head_P/head_E
输出 x0 预测：[B,128,2]（P）与 [B,128,6]（E）
```

- 四套编码：`φ(x,y)` 空间（Sinusoidal2DPositionEmbedding, scale=128）、`ψ(k)` 规划序号（1D 正弦）、token-type/role embedding、扩散时间 t（正弦+MLP，经 AdaLN 注入）。
- 自注意力带结构偏置：`B_horizon(|k_i−k_j|) + B_type(r_i,r_j) + B_pair(T_k↔E_k)`。
- 采样用 **x0-prediction + DDIM**（16 步 cosine 下 ε-DDPM 除以 √ā_t≈0.003 数值爆炸；文档允许只换 head 目标不改结构）。

## 数据（`scripts/data/build_scene_dataset_v1.py` → `data/processed_scene_v1/`）

- `positions [N,128,2]`、`conditions [N,2,2]`、`ellipses6 [N,128,6]`、`maze_id [N]`（0=umaze 1=medium 2=large）。
- 椭圆 = 128 个 waypoint 一一对应（**含 E0/起点**）；e6 = `[c-p, log a, log b, cos2θ, sin2θ]`。
- **去掉 valid 门控**：直接采用离线 IRIS 全部已存参数；仅对无解/退化行兜底（中心=waypoint 的小椭圆 r0=0.02），实测 0 行触发 → 无 invalid 概念、无 masked loss。

## 冒烟结果（2025-09 本机 20 epoch × 250 步/epoch，RTX 4070）

| maze | collision frac | clearance p05 | ellipse sane | center free |
|---|---:|---:|---:|---:|
| umaze | 0.0000 | +0.107 | 1.000 | 0.999 |
| medium | 0.2039 | −0.050 | 1.000 | 0.776 |
| large  | 0.2566 | −0.050 | 1.000 | 0.600 |

端点误差恒为 0（硬条件）。umaze 测试近乎完美；medium/large 是更长走廊，还需更多训练轮/更强正则。
