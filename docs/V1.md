# V1 / V1.1: Occupancy-Conditioned Joint Trajectory–Geometry Diffusion Transformer

按 `docs/联合扩散.md` + `docs/ChatGPT-椭圆条件轨迹扩散-20260907-0210.md` 实现
（V1.1 = Global 16×16 + Fine-Geometry 32×32 双 scene memory；不兼容旧 z-残差/
三阶段/顺序椭圆支路）。

## 网络（`src/models/joint/`）

```
occ [B,1,256,256] → SceneCNN encoder (ch 32→64→96→128→128)
      ├─ global 16×16 → 256 map tokens (f+φ) → C_G = [S,G,M_1..M_256]  [B,258,d]
      └─ fine decoder 16→(fuse F32)→D32→(fuse F64)→D64 → stride-2 → G32
           → 1024 geometry tokens (g+φ) → C_E [B,1024,d]  (无 S/G)

T_k = MLP_P(p_k^t) + ψ(k) + e_traj + w_t φ(p_k^t)
E_k = MLP_E(e_k^t)  + ψ(k) + e_ell  + w_t φ(p_k^t)      w_t = √ā_t
Z = [T_1,E_1,...,T_128,E_128]  → 8×JointBlock:
      AdaLN + JointSelfAttn(relative bias) → GlobalCA(Q=Z, KV=C_G)
      → [仅 2/4/6/8 层] GeometryCA(Q=E only, KV=C_E) + noise-aware spatial bias
      → FFN  → 拆回 → head_P/head_E（x0 预测）
输出：[B,128,2]（P₀̂）与 [B,128,6]（E₀̂）
```

- Noise-aware geometry bias（仅一次预计算，`_geometry_bias`）：
  `B_kj = −ā_t·‖p_k^t − q_j‖²/(2σ²)`，σ=0.25，clamp [−8,0]；高噪≈0 → 全局检索，低噪聚焦局部。
- 采样：**x0-prediction + DDIM**（完整 16 步逐级；`--steps S` 走真正跨步 `x_t→x_s`，s=下一个选定 timestep，s=0 直接给 x0̂）。
- 四套编码：`φ(x,y)`（Sinusoidal2DPositionEmbedding, scale=128）、`ψ(k)` 1D 规划序号、type/role embedding、时间 t（经 AdaLN）。
- 自注意力偏置：`B_horizon(|k_i−k_j|) + B_type(r_i,r_j) + B_pair(T_k↔E_k)`。
- 分辨率 ablation 配置：`configs/config_v1_mem8.yaml`（global 8）、`configs/config_v1_mem32.yaml`（global 32）；V1.1 默认 global 16 + geo 32。

## 数据（`scripts/data/build_scene_dataset_v1.py` → `data/processed_scene_v1/`）

- `positions [N,128,2]`、`conditions [N,2,2]`、`ellipses6 [N,128,6]`、`maze_id [N]`（0=umaze 1=medium 2=large）。
- 椭圆 = 128 个 waypoint 一一对应（**含 E0/起点**）；e6 = `[c-p, log a, log b, cos2θ, sin2θ]`。
- **去掉 valid 门控**：直接采用离线 IRIS 全部已存参数；仅对无解/退化行兜底（中心=waypoint 的小椭圆 r0=0.02），实测 0 行触发 → 无 invalid 概念、无 masked loss。

## 冒烟结果（2025-09 本机 20 epoch × 250 步/epoch，RTX 4070）

| maze | collision frac | clearance p05 | ellipse sane | center free |
|---|---:|---:|---:|---:|
| umaze | 0.0000 | +0.107 | 1.000 | 0.999 |
| medium | 0.2039 | −0.050 | 1.000 | 0.776 |
| large  | 0.2566 | −0.050 | 1.000 | 0.600 |

端点误差恒为 0（硬条件）。umaze 测试近乎完美；medium/large 是更长走廊，还需更多训练轮/更强正则。
