# 轨迹保留与物理速度边界

后续已修正终点版本取消异步结果、提前续接和扩大时空预测检查范围，最新结果与每次实际终点见 [终点与换轨审计.md](终点与换轨审计.md)。本页保留速度边界引入过程及对应历史数据。

## 当前实现

模型仍生成原来的几何 B 样条。没有给几何参数 u 擅自指定秒数，也没有把控制点导数当成 m/s。速度边界施加在物理弧长速度剖面上，不改变 checkpoint、网络或另造几何曲线。

新轨迹通过几何、车身及动态安全检查后，在**实际接入时刻**的最近点固定速度为当前车辆实测速度，而不是使用异步请求发出时的旧速度。当前验证的末端边界固定为 0 m/s，局部轨迹保留可停车的终点；接近局部终点时提前规划延长，最终目的地则直接保留停车轨迹。非零末端速度尚未验证，配置为非零会明确拒绝，不能宣称支持。

前后向扫描约束每段 `(v[i+1]^2-v[i]^2)/(2*ds)`，分别不超过 1.5 m/s² 加速、2.5 m/s² 减速，同时满足曲率/跟车限速。边界不能满足时拒绝候选，不抬高安全限速。已接入的参考速度不逐帧重新锚定，实时安全限速仍可降低执行速度。

控制器加入沿弧长的加速度前馈，允许速度边界为 0 时正常起步；减速前馈按实际车速与参考速度之比缩放，避免在终点前平衡成静止。碰撞预测同步计入这些加速度。这里固定的是**参考速度的标量边界**；实际 CARLA 车速由动力学控制跟踪，不能声称物理车速精确等于参考值，或三维速度向量被硬固定。

## 减少换轨

已有轨迹仍安全、可跟踪且满足当前目标车道时，不因新候选或局部目标版本更新而替换。只有无轨迹、目标车道变化、当前轨迹被占用/有动态风险、跟踪偏差过大、局部轨迹剩余距离不足时才提交重规划；1 Hz 是触发后的重试上限。最终目的地停车轨迹不因“剩余距离小”反复重规划。

每帧保留动态车身碰撞预测及当前膨胀占据检查；已验收的静态道路车身几何在允许道路区域变化时重新检查。新候选仍须通过完整道路车身检查。候选返回后再次检查旧轨迹是否仍可用，可返回 `KEEP_SAFE_PATH`。

真实 RGB 视频只画当前执行轨迹，候选继续保存到日志和独立调试视频。绘线寿命缩短为 0.19 s，低于 0.20 s 刷新周期。

与相机修复版本的 18 次接入相比，本次为 5 次；异步推理时序不同，不能把单次差异解释为严格统计意义的消融结论。当前仍有超期/被拒候选，完整推理 P50 941.9 ms、P95 1766.6 ms；未宣称达到 5–10 Hz。

可通过 `scripts/audit_carla_speed_boundaries.py <运行目录>` 独立检查已接入轨迹保存的参考速度、起点实测匹配和全部加减速分段约束。上述历史失败保留，不与最终代码的验收混用。
