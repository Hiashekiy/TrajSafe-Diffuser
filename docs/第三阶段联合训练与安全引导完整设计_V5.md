# 第三阶段 Joint Safety Fine-tuning 完整设计报告（V5）

## 1. 设计目标

当前训练已经分成两个稳定阶段：

### Phase 1：轨迹阶段 `--phase traj`

只训练轨迹主干：

\[
L_{\mathrm{traj}}^{(1)}
=
\lambda_zL_Z
+
\lambda_pL_p
+
\lambda_{sm}L_{\mathrm{smooth}}
\]

当前权重：

\[
\lambda_z=1.0,\qquad
\lambda_p=0.5,\qquad
\lambda_{sm}=0.2.
\]

其中：

- \(L_Z\)：零和残差 \(z_0^{pred}\) 与 \(z_0^{gt}\) 的 MSE；
- \(L_p\)：中间路点位置 MSE；
- \(L_{\mathrm{smooth}}\)：残差二阶差分 Huber。

Phase 1 的任务是让 Diffusion 首先学会稳定地产生合理轨迹。

---

### Phase 2：椭圆阶段 `--phase ellipse`

加载轨迹 checkpoint，冻结轨迹主干，训练椭圆分支：

\[
L_E
=
\lambda_{\mathrm{param}}L_{\mathrm{param}}
+
\lambda_{\mathrm{iou}}L_{\mathrm{iou}}
+
\lambda_{\mathrm{coll}}L_{\mathrm{ecoll}}
+
\lambda_{\mathrm{anchor}}L_{\mathrm{anchor}}.
\]

其中：

\[
L_{\mathrm{param}}
=
L_{\mathrm{center}}
+
L_{\mathrm{radius}}
+
L_{\theta}.
\]

当前权重保持：

\[
\lambda_{\mathrm{param}}=10,
\qquad
\lambda_{\mathrm{iou}}=5,
\qquad
\lambda_{\mathrm{coll}}=2,
\qquad
\lambda_{\mathrm{anchor}}=5.
\]

Phase 2 的任务是让模型沿预测轨迹生成可靠的局部安全椭圆，并进一步构造不与障碍碰撞的局部安全凸区域：

\[
\boxed{
\mathcal P_k
=
\{x\mid A_kx\le b_k\}
}
\]

---

## 2. Phase 3 的重新定位

第三阶段不再重复做“轨迹 GT 回归”。

第三阶段定位为：

\[
\boxed{
\text{Safety-constrained Joint Fine-tuning}
}
\]

也就是：

> 在 Phase 1 已经学会生成轨迹、Phase 2 已经学会预测局部安全几何的基础上，让轨迹开始主动服从安全凸区域，同时保留必要的轨迹自由度。

因此第三阶段不再把：

\[
z_0^{pred}\rightarrow z_0^{gt}
\]

和：

\[
p^{pred}\rightarrow p^{gt}
\]

作为核心优化目标。

第三阶段真正关心的是：

\[
\boxed{
\text{轨迹是否平滑}
+
\text{椭圆几何是否可靠}
+
\text{轨迹是否满足安全凸区域}
}
\]

---

# 2.1 Phase 3 微调范围：冻结底层编码层

第三阶段是基于 Phase 1 + Phase 2 checkpoint 的安全微调，不重新学习底层场景和轨迹表示。

采用最简单的限制：

\[
\boxed{
\text{冻结底层编码层}
+
\text{只训练轨迹生成端和椭圆生成端}
+
\text{使用小学习率}
}
\]

### 冻结模块

第三阶段固定：

- `SceneEncoder`
- `TrajectoryEncoder`
- `PointSceneAttention`

这些模块继续参与 forward，但参数：

```python
requires_grad = False
```

不进入 optimizer。

`LocalSampler` 若本身无可训练参数，则正常使用即可。

### 训练模块

轨迹生成端：

- `SafetyFusion`
- `TrajectoryDecoder`
- `ResidualHead`

椭圆生成端：

- `EllipseAggregator`
- `EllipseHead`
- `ellipse_pe_embed`

即：

```text
Frozen
├── SceneEncoder
├── TrajectoryEncoder
└── PointSceneAttention

Trainable
├── SafetyFusion
├── TrajectoryDecoder
├── ResidualHead
├── EllipseAggregator
├── EllipseHead
└── ellipse_pe_embed
```

这样第三阶段固定“如何编码场景和轨迹状态”，只允许模型调整：

\[
\boxed{
\text{轨迹怎么生成}
}
\]

以及：

\[
\boxed{
\text{椭圆怎么生成}
}
\]

能够给安全约束留下必要自由度，同时避免把前两阶段已经学好的底层表示重新训练。

---

# 3. 第三阶段删除 \(L_Z\) 和 \(L_p\)

第三阶段主损失中设置：

\[
\boxed{
L_Z=0
}
\]

\[
\boxed{
L_p=0
}
\]

原因是：

\[
L_Z,\;L_p
\]

都会把轨迹持续拉回原始 Ground Truth。

但是第三阶段需要允许：

\[
\boxed{
\text{轨迹为了安全性发生必要的局部改变}
}
\]

如果继续保留较强的 \(L_Z,L_p\)，就会形成：

\[
\text{GT imitation}
\quad\leftrightarrow\quad
\text{Safety refinement}
\]

的直接竞争。

因此 Phase 3 不再要求：

> 轨迹必须尽可能接近原来的 GT。

而改成：

> 轨迹保持合理和平滑即可，在此基础上允许安全约束重新调整局部形状。

---

# 4. 保留 \(L_{\mathrm{smooth}}\)

第三阶段仍然保留：

\[
\boxed{
L_{\mathrm{smooth}}
}
\]

因为安全约束会从多个局部凸区域给轨迹施加梯度。

如果没有轨迹平滑项，可能出现：

\[
\text{满足局部安全约束}
\]

但：

\[
\text{轨迹产生局部折线、锯齿或高频摆动}.
\]

因此：

\[
L_{\mathrm{smooth}}
=
\operatorname{Huber}
\left(
z_{k+1}-2z_k+z_{k-1}
\right).
\]

第三阶段建议降低其权重，使它只承担“抑制高频变化”的职责，而不是限制轨迹整体调整。

初始建议：

\[
\boxed{
\lambda_{sm}^{joint}=0.05\sim0.1
}
\]

Phase 1 中的 \(0.2\) 不必直接照搬。

---

# 5. 椭圆损失 \(L_E\) 完整保留

第三阶段中，Phase 2 已经使用的椭圆损失不修改：

\[
\boxed{
L_E
=
10L_{\mathrm{param}}
+
5L_{\mathrm{iou}}
+
2L_{\mathrm{ecoll}}
+
5L_{\mathrm{anchor}}
}
\]

内部：

\[
L_{\mathrm{param}}
=
L_{\mathrm{center}}
+
L_{\mathrm{radius}}
+
L_\theta.
\]

不重新修改：

- center loss；
- radius loss；
- double-angle orientation loss；
- soft IoU；
- ellipse collision；
- anchor loss。

第一版 Joint Training 直接保留 Phase 2 的完整 \(L_E\)。

---

# 6. 第三阶段不加入局部共识中心线 Training Loss

这是本版设计的重要修改。

之前将局部共识中心线写成：

\[
L_{\mathrm{cons}}
\]

并放入第三阶段训练总损失。

这一做法取消。

局部共识中心线的真正用途是：

\[
\boxed{
\text{Reverse Diffusion 中的 Gradient Guidance}
}
\]

而不是监督网络参数的常规 Training Loss。

为了避免概念混淆，后续不再称：

\[
L_{\mathrm{cons}}
\]

而统一改名为：

\[
\boxed{
J_{\mathrm{guide}}
}
\]

或者：

\[
\boxed{
C_{\mathrm{guide}}
}
\]

表示一个**推理阶段的 Guidance Cost / Potential**。

因此：

\[
\boxed{
J_{\mathrm{guide}}
\notin
L_{\mathrm{joint}}
}
\]

---

# 7. 第三阶段最终训练损失

最终主损失修改为：

\[
\boxed{
L_{\mathrm{joint}}
=
\lambda_{sm}^{joint}L_{\mathrm{smooth}}
+
L_E
+
w_{\mathrm{epoch}}(e)
w_{\mathrm{AL}}(t)
L_{\mathrm{AL}}
}
\]

其中：

- \(L_{\mathrm{smooth}}\)：保持局部平滑；
- \(L_E\)：保持并联合优化椭圆预测；
- \(L_{\mathrm{AL}}\)：新增安全凸区域约束；
- \(w_{\mathrm{epoch}}(e)\)：Phase 3 训练阶段渐进开启；
- \(w_{\mathrm{AL}}(t)\)：根据 diffusion timestep 控制安全约束何时介入。

明确不加入：

\[
\boxed{
L_Z,\quad
L_p,\quad
J_{\mathrm{guide}}
}
\]

建议同时关闭原先单椭圆：

\[
L_{\mathrm{align}}
\]

因为后续推理 Guidance 已经使用多椭圆局部共识方向。

若原 Joint 阶段存在单独轨迹碰撞损失 \(L_{\mathrm{col}}\)，主方案中也不作为核心安全项，因为当前无碰撞凸区域已经承担轨迹安全约束；collision rate 继续作为验证指标和消融项。

---

# 8. 安全凸区域约束

第 \(k\) 个局部安全凸区域：

\[
\boxed{
\mathcal P_k
=
\{x\mid A_kx\le b_k\}
}
\]

对应第 \(k\) 个轨迹 segment：

\[
S_k=[p_k,p_{k+1}].
\]

由于 \(\mathcal P_k\) 是凸集，只要：

\[
p_k\in\mathcal P_k
\]

并且：

\[
p_{k+1}\in\mathcal P_k,
\]

就必然有：

\[
\boxed{
[p_k,p_{k+1}]
\subseteq
\mathcal P_k
}
\]

因此不需要在线段中间额外采样大量点。

---

# 9. 相邻凸区域自动形成连接约束

连续两个 segment：

\[
[p_k,p_{k+1}]
\]

和：

\[
[p_{k+1},p_{k+2}]
\]

分别受到：

\[
\mathcal P_k
\]

和：

\[
\mathcal P_{k+1}
\]

约束。

共享点 \(p_{k+1}\) 自动满足：

\[
p_{k+1}\in\mathcal P_k
\]

同时：

\[
p_{k+1}\in\mathcal P_{k+1}.
\]

因此：

\[
\boxed{
p_{k+1}
\in
\mathcal P_k
\cap
\mathcal P_{k+1}
}
\]

所以不额外增加 overlap loss。

---

# 10. 单条半空间约束

第 \(k\) 个凸区域第 \(i\) 条边：

\[
a_{k,i}^{T}x
\le
b_{k,i}.
\]

建议首先将法向量单位化：

\[
\boxed{
\|a_{k,i}\|_2=1
}
\]

这样不同边界的 residual 尺度一致。

对 segment 两个端点：

\[
r_{k,i}^{(0)}
=
a_{k,i}^{T}p_k-b_{k,i}+\delta,
\]

\[
r_{k,i}^{(1)}
=
a_{k,i}^{T}p_{k+1}-b_{k,i}+\delta.
\]

其中：

\[
\delta\ge0
\]

为可选 safety margin。

第一版：

\[
\boxed{
\delta=0
}
\]

含义：

- \(r<0\)：位于安全侧；
- \(r=0\)：在边界；
- \(r>0\)：越界。

---

# 11. 多边界共同作用，不使用 Max-1

不能只取：

\[
\max_i r_i.
\]

原因是轨迹在凸区域角点附近时，两条边界可能同时接近 active。

例如：

\[
r_{\mathrm{right}}=0.081,
\qquad
r_{\mathrm{top}}=0.079.
\]

下一步变成：

\[
r_{\mathrm{right}}=0.078,
\qquad
r_{\mathrm{top}}=0.082.
\]

如果每一步只使用最大的约束，梯度方向可能在：

\[
\leftarrow
\]

和：

\[
\downarrow
\]

之间切换。

因此使用：

\[
\boxed{
\text{Soft Active-Set}
}
\]

让多个危险边界同时提供梯度。

---

# 12. Soft Active-Set

对于端点：

\[
s\in\{0,1\},
\]

定义：

\[
\boxed{
\alpha_{k,i}^{(s)}
=
\frac{
\exp(\beta r_{k,i}^{(s)})
}{
\sum_j
\exp(\beta r_{k,j}^{(s)})
}
}
\]

其中：

\[
\beta>0
\]

控制权重集中程度。

- \(\beta\) 较小：多个边界共同参与；
- \(\beta\) 较大：越来越接近 Max-1。

初始建议：

\[
\boxed{
\beta=15
}
\]

并在：

\[
10,\;15,\;20
\]

之间做小范围验证。

---

# 13. 只处罚正违反量，避免安全边界抵消危险边界

定义：

\[
\boxed{
v_{k,i}^{(s)}
=
[r_{k,i}^{(s)}]_+
=
\max(0,r_{k,i}^{(s)})
}
\]

这样已经满足约束的负 residual 不会抵消真正的越界量。

定义多边界平均违反：

\[
\boxed{
V_k^{(s)}
=
\sum_i
\alpha_{k,i}^{(s)}
v_{k,i}^{(s)}
}
\]

以及平方违反：

\[
\boxed{
Q_k^{(s)}
=
\sum_i
\alpha_{k,i}^{(s)}
\left(v_{k,i}^{(s)}\right)^2
}
\]

因此：

- 一条边危险时，该边贡献最大；
- 两条边同时危险时，两条边共同产生梯度；
- 所有边都安全时：
  \[
  V_k^{(s)}=Q_k^{(s)}=0.
  \]

---

# 14. Augmented-Lagrangian-style 安全项

当前训练中的：

\[
A_k,b_k
\]

会随：

- batch；
- 地图；
- trajectory；
- ellipse；

不断变化。

因此不建议长期维护固定：

\[
\lambda_{k,i}
\]

因为不同 batch 中的“第 \(k\) 个区域第 \(i\) 条边”并不是同一个物理约束。

使用一个全局安全 dual variable：

\[
\lambda_{\mathrm{dual}}\ge0.
\]

对当前有效 batch：

\[
\bar V
=
\operatorname{mean}_{B,k,s}
V_{B,k}^{(s)},
\]

\[
\bar Q
=
\operatorname{mean}_{B,k,s}
Q_{B,k}^{(s)}.
\]

安全损失：

\[
\boxed{
L_{\mathrm{AL}}
=
\lambda_{\mathrm{dual}}\bar V
+
\frac{\rho}{2}\bar Q
}
\]

第一项：

\[
\lambda_{\mathrm{dual}}\bar V
\]

反映整体安全违反。

第二项：

\[
\frac{\rho}{2}\bar Q
\]

对严重违规产生更大的惩罚。

---

# 15. Dual Variable 更新

每隔若干 optimizer step：

\[
\boxed{
\lambda_{\mathrm{dual}}
\leftarrow
\operatorname{clip}
\left(
\lambda_{\mathrm{dual}}
+
\eta_\lambda\bar V,
0,
\lambda_{\max}
\right)
}
\]

推荐初始：

```yaml
dual_init: 0.1
dual_max: 10.0
rho: 5.0
dual_lr: 0.1
dual_update_interval: 10
```

需要注意：

\[
\boxed{
\text{只有进入 AL 有效 timestep 的样本才参与 dual update}
}
\]

高噪声阶段不应该因为不可靠几何而把 dual variable 推高。

---

# 16. AL 安全梯度只修正轨迹

在 \(L_{\mathrm{AL}}\) 中：

```python
A_safe = A.detach()
b_safe = b.detach()
```

而：

\[
p_k
\]

不 detach。

因此：

\[
\boxed{
L_{\mathrm{AL}}
\rightarrow
p
\rightarrow
z_0
\rightarrow
TrajectoryNet
}
\]

而不允许：

\[
L_{\mathrm{AL}}
\rightarrow
A,b
\rightarrow
EllipseNet.
\]

含义是：

> 当前凸区域作为已经构造好的安全参考，安全 loss 应该让轨迹服从区域，而不是让区域移动去迁就轨迹。

Ellipse branch 本身继续由：

\[
L_E
\]

训练。

---

# 17. 为什么 AL 不能从高噪声阶段开始生效

reverse diffusion：

\[
z_{T-1}
\rightarrow
z_{T-2}
\rightarrow
\cdots
\rightarrow
z_0.
\]

在：

\[
t\approx T-1
\]

时：

- 当前 noisy state 很不稳定；
- \(\hat z_0\) 的整体拓扑仍在形成；
- 恢复出的 \(\hat p\) 可能仍有较大变化；
- 根据 \(\hat p\) 预测的 ellipse 也更不稳定；
- 对应 convex region 虽然可能本身无碰撞，但未必已经是当前最终轨迹应该服从的局部安全走廊。

因此高噪声阶段强行施加：

\[
L_{\mathrm{AL}}
\]

可能导致：

\[
\boxed{
\text{局部安全约束过早介入}
\rightarrow
\text{干扰 Diffusion 决定整体轨迹拓扑}
}
\]

所以必须增加 diffusion timestep gate。

---

# 18. AL 的 timestep gate

定义：

\[
t_{\mathrm{AL,start}}
\]

和：

\[
t_{\mathrm{AL,full}}.
\]

注意 reverse diffusion 中：

\[
t
\]

从大到小。

定义：

\[
\boxed{
w_{\mathrm{AL}}(t)
=
\begin{cases}
0,
&
t>t_{\mathrm{AL,start}}
\\[4pt]
\dfrac{
t_{\mathrm{AL,start}}-t
}{
t_{\mathrm{AL,start}}-t_{\mathrm{AL,full}}
},
&
t_{\mathrm{AL,full}}<t\le t_{\mathrm{AL,start}}
\\[10pt]
1,
&
t\le t_{\mathrm{AL,full}}
\end{cases}
}
\]

即：

### 高噪声

\[
t>t_{\mathrm{AL,start}}
\]

完全不加入 AL。

### 中噪声

\[
t_{\mathrm{AL,full}}
<
t
\le
t_{\mathrm{AL,start}}
\]

逐渐增强。

### 低噪声

\[
t
\le
t_{\mathrm{AL,full}}
\]

完整启用。

# 19. AL 初始开启位置

不要把具体 timestep 写死为固定数字，建议使用相对比例。

初始值：

\[
\boxed{
t_{\mathrm{AL,start}}
\approx
0.6(T-1)
}
\]

\[
\boxed{
t_{\mathrm{AL,full}}
\approx
0.2(T-1)
}
\]

例如：

\[
T=100
\]

则初始可用：

\[
t_{\mathrm{AL,start}}\approx60
\]

\[
t_{\mathrm{AL,full}}\approx20.
\]

含义：

```text
t=99 ------------------------------ 0

      Diffusion 自由生成
99 -------- 60

            AL 逐渐开启
            60 ---------------- 20

                                AL 完整启用
                                20 ------- 0
```

这些只是初始值，最终应根据验证结果确定。

# 20. Phase 3 epoch ramp

除了 diffusion timestep gate，还需要避免 Phase 3 第一个 epoch 就把安全约束完全打开。

定义：

\[
\boxed{
w_{\mathrm{epoch}}(e)
=
\min
\left(
1,
\frac{e}{E_{\mathrm{ramp}}}
\right)
}
\]

推荐：

\[
\boxed{
E_{\mathrm{ramp}}
=
0.2E_{\mathrm{joint}}
}
\]

即前 20% Joint Training：

\[
0\rightarrow1
\]

逐渐增加安全训练强度。

最终有效安全权重为：

\[
\boxed{
w_{\mathrm{safe}}(e,t)
=
w_{\mathrm{epoch}}(e)
w_{\mathrm{AL}}(t)
}
\]

因此：

\[
\boxed{
L_{\mathrm{joint}}
=
\lambda_{sm}^{joint}L_{\mathrm{smooth}}
+
L_E
+
w_{\mathrm{safe}}(e,t)L_{\mathrm{AL}}
}
\]

# 21. 如何选择真正合适的 AL 开启 timestep

不应该只凭经验固定：

\[
0.6T.
\]

建议在 Phase 2 checkpoint 上先做一个 timestep stability profile。

将：

\[
t\in[0,T-1]
\]

分成若干区间，例如 10 个 bin。

分别统计：

### 轨迹稳定性

- position error / ADE；
- goal error；
- trajectory smoothness；
- 与 \(t=0\) 轨迹的变化量。

### 椭圆稳定性

- center error；
- radius error；
- ellipse IoU；
- anchor inside rate；
- angle error / direction consistency。

### 凸区域稳定性

- region construction success rate；
- region area；
- trajectory point containment rate；
- adjacent region overlap rate。

然后选择：

\[
t_{\mathrm{AL,start}}
\]

使得：

> 从该 timestep 往后，轨迹和局部安全几何已经进入相对稳定区间。

因此：

\[
0.6T
\]

只是工程初值，而不是方法本身的固定常数。

---

# 22. 局部共识中心线只用于 Sampling Guidance

推理阶段，轨迹已经逐步形成以后，利用：

\[
E_{k-2},
E_{k-1},
E_k,

# 25. 方向共识置信度

double-angle mean 的长度：

\[
\boxed{

可用于描述邻域 ellipse direction 的一致程度。

- 连续稳定走廊；

Guidance 强。

在：

- 急转角；
- 交叉区域；
- ellipse orientation 不稳定；

Guidance 自动减弱。

# 26. 共识中心线 Guidance Cost

定义：

\[
\bar n_k
=
\begin{bmatrix}
-\bar u_{k,y}\\
\bar u_{k,x}
\end{bmatrix}.
\]

轨迹点到共识中心线的横向偏差：

\[
d_k^\perp
=
\bar n_k^T
(p_k-\bar c_k).
\]

邻域短半轴：

\[
\bar r_{2,k}
=
\frac{
\sum_j
\omega_{k,j}r_{2,j}
}{
\sum_j
\omega_{k,j}+\varepsilon
}.
\]

归一化：

\[
\delta_k
=
\frac{
d_k^\perp
}{
\bar r_{2,k}+\varepsilon
}.
\]

平均离心率：

\[
\bar e_k
=
\frac{
\sum_j
\omega_{k,j}^{pos}e_j
}{
\sum_j
\omega_{k,j}^{pos}+\varepsilon
}.
\]

最终局部 Guidance confidence：

\[
\boxed{
\gamma_k
=
\bar e_kq_k
}
\]

定义：

\[
\boxed{
J_{\mathrm{guide}}
=
\frac1N
\sum_k
\gamma_k
\rho(\delta_k)
}
\]

其中：

\[
\rho
\]

使用 Huber。

注意：

\[
\boxed{

\text{ 不是 training loss}
}

这里的“不是 training loss”仅表示：不把 \(J_{\mathrm{guide}}\) 作为一个标量项
直接加到 \(L_{\mathrm{joint}}\) 中，也不为它设置独立的 loss weight。它并不表示
\(J_{\mathrm{guide}}\) 在训练阶段完全不发挥作用。训练时可以先根据
\(\nabla_{\hat z_0}J_{\mathrm{guide}}\) 对模型输出的 \(\hat z_0\) 做一次可微的
guidance correction，再使用修正后的轨迹计算 \(L_{\mathrm{smooth}}\)、\(L_E\)
和 \(L_{\mathrm{AL}}\)。此时 \(J_{\mathrm{guide}}\) 通过“修正后的模型输出”

# 34. `total_loss.py` 建议结构

```python
def total_loss(..., phase, diffusion_t, epoch, ...):

    if phase == "traj":
        total = (
            lambda_z * l_z
            + lambda_p * l_p
            + lambda_smooth * l_smooth
        )
        return total

    if phase == "ellipse":
        total = ellipse_loss
        return total

    if phase == "joint":

        # 1. 保留平滑
        loss = lambda_smooth_joint * l_smooth

        # 2. 完整保留 Phase 2 ellipse loss
        loss = loss + ellipse_loss

        # 3. 只在合适 timestep 启用 AL
        w_t = al_timestep_weight(diffusion_t)
        w_e = joint_epoch_ramp(epoch)

        loss = loss + w_t * w_e * loss_al

        return loss
```

明确：

```python
# joint phase
l_z_weight = 0.0
l_p_weight = 0.0
l_cons_weight = 0.0
```

因为：

\[
J_{\mathrm{guide}}
\]

不作为独立加和项写入 `total_loss.py`。如果训练实现采用“先 guidance 修正
输出、再计算其他损失”的方案，guidance 逻辑应放在训练 forward 或独立
guidance 模块中，并保持其几何参数 detach；此时它仍可通过修正后的输出
影响后续损失的梯度。

# 36. AL 伪代码

```python
# p0 / p1: [B, N, 2]
# A: [B, N, M, 2]
# b: [B, N, M]
# edge_mask: [B, N, M]

A_safe = A.detach()
b_safe = b.detach()

# 建议构造 convex region 时就保证 ||a|| = 1
r0 = torch.einsum("bnmd,bnd->bnm", A_safe, p0) - b_safe
r1 = torch.einsum("bnmd,bnd->bnm", A_safe, p1) - b_safe

r0 = r0 + margin
r1 = r1 + margin

# invalid padded edges 不参与 softmax
r0_logits = (beta * r0).masked_fill(~edge_mask, -1e9)
r1_logits = (beta * r1).masked_fill(~edge_mask, -1e9)

alpha0 = torch.softmax(r0_logits, dim=-1)
alpha1 = torch.softmax(r1_logits, dim=-1)

v0 = torch.relu(r0)
v1 = torch.relu(r1)

V0 = (alpha0 * v0).sum(dim=-1)
V1 = (alpha1 * v1).sum(dim=-1)

Q0 = (alpha0 * v0.square()).sum(dim=-1)
Q1 = (alpha1 * v1.square()).sum(dim=-1)

V = torch.cat([V0, V1], dim=-1)
Q = torch.cat([Q0, Q1], dim=-1)

mean_V = masked_mean(V, segment_mask)
mean_Q = masked_mean(Q, segment_mask)

loss_al = lambda_dual * mean_V + 0.5 * rho * mean_Q
```

# 37. AL timestep schedule 伪代码

```python
def al_timestep_weight(t, T, start_ratio=0.60, full_ratio=0.20):
    t_start = start_ratio * (T - 1)
    t_full  = full_ratio  * (T - 1)

    # high noise
    if t > t_start:
        return 0.0

    # low noise
    if t <= t_full:
        return 1.0

    # linear ramp
    return (t_start - t) / (t_start - t_full)
```

训练时 \(t\) 通常是 batch tensor，因此实际实现使用 tensorized clamp：

```python
w_t = ((t_start - t) / (t_start - t_full)).clamp(0.0, 1.0)
```

再对 batch loss 做逐样本加权。

# 38. Guidance timestep schedule 伪代码

```python
def guidance_weight(t, T, start_ratio=0.40, full_ratio=0.10):
    t_start = start_ratio * (T - 1)
    t_full  = full_ratio  * (T - 1)

    return ((t_start - t) / (t_start - t_full)).clamp(0.0, 1.0)
```

最终：

```python
eta_t = eta_max * guidance_weight(t, T)
```

并进一步通过局部：

\[
\gamma_k
\]

控制每个 waypoint 的实际 Guidance confidence。

因此最终 Guidance 同时具有：

\[
\boxed{
\text{全局 timestep confidence}
\times
\text{局部 ellipse consensus confidence}
}
\]

# 40. 微调实现：冻结 + 小学习率

第三阶段不增加额外正则项，也不采用复杂的渐进解冻。

只使用两个限制：

\[
\boxed{
\text{冻结底层编码层}
+
\text{小学习率}
}
\]

统一微调学习率第一版建议：

\[
\boxed{
LR_{\mathrm{joint}}=1\times10^{-5}
}
\]

若 Phase 1 / Phase 2 使用的是：

\[
10^{-4}
\]

则相当于降低一个数量级。

实现：

```python
# 1. 先冻结全部参数
for p in model.parameters():
    p.requires_grad = False

# 2. 只打开轨迹生成端和椭圆生成端
trainable_modules = [
    model.safety_fusion,
    model.trajectory_decoder,
    model.residual_head,
    model.ellipse_aggregator,
    model.ellipse_head,
    model.ellipse_pe_embed,
]

for module in trainable_modules:
    for p in module.parameters():
        p.requires_grad = True

# 3. optimizer 只接收可训练参数
trainable_params = [
    p for p in model.parameters()
    if p.requires_grad
]

optimizer = torch.optim.AdamW(
    trainable_params,
    lr=1e-5,
    weight_decay=1e-4,
)
```

如果 `ellipse_pe_embed` 在当前实现中不是 `nn.Module`，则直接把其参数加入 `trainable_params`，不需要额外改变网络结构。

第三阶段不再设置多组复杂 learning rate。

核心原则只有：

\[
\boxed{
\text{底层表示不动，只用小步长调整生成结果}
}
\]

p_k^{joint}
-
p_k^{phase1}
\|_2
}
\]

该指标默认：

\[
\text{只监控，不进入 loss}.
\]

如果实验发现明显 drift，再考虑加入很弱的 trust-region 约束，而不是直接恢复 \(L_p\)。

# 44. Checkpoint 选择

不建议只根据：

\[
L_{\mathrm{joint}}
\]

最小选择 best checkpoint。

优先看：

1. trajectory unsafe rate；
2. maximum violation；
3. segment violation；
4. collision rate。

在安全性相近的 checkpoint 中，再选择：

- goal error 更低；
- smoothness 更好；
- \(D_{\mathrm{phase1}}\) 更小；

的模型。

即：

\[
\boxed{
\text{先满足安全，再比较轨迹质量}
}

# 48. 最终第三阶段公式与微调策略

最终训练：

\[
\boxed{
L_{\mathrm{joint}}(e,t)
=
\lambda_{sm}^{joint}L_{\mathrm{smooth}}
+
L_E
+
w_{\mathrm{epoch}}(e)
w_{\mathrm{AL}}(t)
L_{\mathrm{AL}}
}
\]

其中：

\[
\boxed{
L_Z=L_p=0
}
\]

并且：

\[
\boxed{
J_{\mathrm{guide}}
\notin
L_{\mathrm{joint}}
}
\]

这里的 \(\notin\) 只表示不把 \(J_{\mathrm{guide}}\) 作为独立标量项加入
训练总损失。它不排斥训练阶段先利用 \(\nabla_{\hat z_0}J_{\mathrm{guide}}\)
构造 \(\hat z_0^{guide}\)，再用该修正结果计算 \(L_{\mathrm{smooth}}\)、
\(L_E\) 和 \(L_{\mathrm{AL}}\)。因此应区分：

```text
显式损失项：J_guide 不加入 L_joint
训练梯度链：J_guide 可以通过 guided output 间接发挥作用
推理采样：J_guide 直接用于 reverse-diffusion correction
```

参数更新范围：

\[
\boxed{
\theta_{\mathrm{frozen}}
=
\{
SceneEncoder,\;
TrajectoryEncoder,\;
PointSceneAttention
\}
}
\]

\[
\boxed{
\theta_{\mathrm{train}}
=
\{
SafetyFusion,\;
TrajectoryDecoder,\;
ResidualHead,\;
EllipseAggregator,\;
EllipseHead,\;
ellipse\_pe\_embed
\}
}
\]

学习率：

\[
\boxed{
LR_{\mathrm{joint}}
\approx10^{-5}
}
\]

最终推理 Guidance：

\[
\boxed{
\hat z_0^{guide}
=
\hat z_0
-
\eta_{\max}
w_G(t)
\nabla_{\hat z_0}
J_{\mathrm{guide}}
}
\]

其中：

\[
\boxed{
t_{\mathrm{AL,start}}
>
t_{\mathrm{G,start}}
}
\]

整体流程：

\[
\boxed{
\text{冻结底层编码}
\rightarrow
\text{小学习率安全微调}
\rightarrow
\text{late-stage convex safety learning}
\rightarrow
\text{later-stage consensus guidance}

}
