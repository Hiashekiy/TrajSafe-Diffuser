# Maze2D 轨迹动力学一致性 —— 详细验证报告

> 对象：data/processed/mixed 混合轨迹标签。
> 目的：确认轨迹标签是否满足动力学一致性，并确定“速度→位置”应该用哪种积分公式。
> 样本：从 train split 随机采样 3000 条 128 步窗口；控制动力学自由/近墙分区用 400 条窗口 + SDF>0.2 判定。
> 结论一句话：
> p_{k+1}=p_k+v_{k+1}*0.01 是最准的积分方式（128 步 ADE≈0.013），
> 自由空间动力学满足 v_{k+1}≈0.996 v_k+0.238 u_k，即 α≈0.996, β≈0.238, b≈0。

---

## 0. 官方时间步长

D4RL Maze2D 官方设置：（参见 Farama-Foundation/D4RL pointmaze/maze_model.py）

- timestep=0.01
- integrator=Euler
- frame_skip=1
- joint damping=1
- motor gear=100

所以我们直接采用：

~~~text
Δt = 0.01
~~~

数据反推（|dx|/|vx|）给的 0.0098~0.0101 是对这套预处理的交叉验证。

---

## 1. 位置-速度积分对齐测试

用混合数据世界坐标，计算三种候选积分公式：

~~~text
A: Δp ≈ v_k * 0.01
B: Δp ≈ v_{k+1} * 0.01
C: Δp ≈ 0.5*(v_k+v_{k+1}) * 0.01
~~~

### 1.1 单步指标

| 公式 | RMSE | MAE | R² |
|---|---|---|---|
| A (v_k) | 0.004039 | 0.003066 | 0.992787 |
| B (v_{k+1}) | 0.002409 | 0.000101 | 0.997435 |
| C (平均) | 0.002839 | 0.001583 | 0.996438 |

B 明显最优，MAE 只有 0.000101，几乎是精确关系。

### 1.2 128 步积分 ADE / FDE

从 p_0 开始按照各公式递推 128 步，与真实位置比较：

| 公式 | ADE | FDE |
|---|---|---|
| A (v_k) | 0.045378 | 0.058228 |
| B (v_{k+1}) | 0.012702 | 0.012802 |
| C (平均) | 0.023291 | 0.031460 |

B 在 128 步累计后仍然最好：ADE=0.0127，FDE=0.0128，远优于 A。

### 1.3 结论

~~~text
p_{k+1} = p_k + v_{k+1} * 0.01
~~~

是这套数据真正采用的位置-速度关系。这也和 MuJoCo/Euler “先更新速度，再用新速度积分位置”的顺序一致。

## 2. 速度-控制输入（action）动力学拟合

用离散模型：

~~~text
v_{k+1} = α v_k + β u_k + b
~~~

拟合（u 为 D4RL 的 action，即混合数据里的 [ax, ay]）。

### 2.1 全部样本拟合

| 轴 | α | β | b |
|---|---|---|---|
| x | 0.996112 | 0.238347 | -0.000220 |
| y | 0.996134 | 0.238800 | -0.000228 |

### 2.2 分区拟合（SDF>0.2 视为自由空间）

| 分区 | 轴 | α | β | b | n |
|---|---|---|---|---|---|
| free | x | 0.996143 | 0.238089 | 0.000065 | 50732 |
| free | y | 0.996313 | 0.238509 | 0.000015 | 50732 |
| nearwall | x | 0.873252 | 0.532190 | 0.021426 | 68 |
| nearwall | y | 0.845040 | 0.419125 | -0.093253 | 68 |

### 2.3 解释

- 自由空间：α≈0.996，β≈0.238，b≈0，非常干净。
- 理论值：
  - 质量 m = 1000 * (4/3) π * (0.1)^3 ≈ 4.18879
  - α = 1 - Δt/m = 1 - 0.01/4.18879 ≈ 0.9976
  - β = gear*Δt/m = 100*0.01/4.18879 ≈ 0.2387
- 实测 β≈0.238，α≈0.996，与理论几乎一致。
- nearwall 只有 68 个点，且 α/β 明显偏离、b 很大，说明接触力/碰撞会把控制动力学显著改变。这是正常的：碰墙时不能用简单自由空间模型。

### 2.4 结论

~~~text
v_{k+1} ≈ α v_k + β u_k
~~~

在自由空间成立，且：

~~~text
α ≈ 0.9961
β ≈ 0.2383
b ≈ 0
~~~

也就是说：[ax, ay] 是 motor control（带增益），不是精确加速度。

## 3. 对轨迹表示设计的含义

已经坐实：

~~~text
p ↔ v 在数据里基本确定为：p_{k+1}=p_k+v_{k+1}*0.01
~~~

所以规划分支更适合改成：

~~~text
Scene-conditioned diffusion → (v_x, v_y) → Integration → (x, y)
~~~

而不是继续让网络独立预测 6 维 [a_x,a_y,x,y,v_x,v_y]。

### 优点

1. 不会出现飞线：p_{k+1}=p_k+v_{k+1}*0.01，速度正常就不可能瞬间空降。
2. 位置和速度天然一致：位置是速度积分出来的。
3. 毛刺会减轻：不再直接回归 128 个独立 (x,y)，而是连续速度序列。
4. Loss 可以简化：
   L_v=MSE(hat V, V_GT)
   L_p=MSE(Integrate(p0,hat V), P_GT)
   L_traj = L_v + λ_p L_p + λ_g L_goal
   不需要之前的 L_var / L_var_vel / L_spread / 旧 L_smooth。

### action 还要不要？

- 主规划器先不生成 action。
- 未来若需要底层执行，可用已验证的模型反解：
  u_k = (v_{k+1} - α v_k) / β
  再 clip 到 [ -1, 1 ]。

## 4. 结论汇总

| 检查项 | 结果 |
|---|---|
| 时间步长 | Δt = 0.01（官方 + 数据反推交叉验证） |
| 最优积分公式 | B：p_{k+1}=p_k+v_{k+1}*0.01 |
| 128 步 ADE/FDE | B: ADE≈0.0127, FDE≈0.0128 |
| 控制动力学 | 自由空间 α≈0.996, β≈0.238, b≈0 |
| action 语义 | motor control，不是加速度 |
| 建议表示 | 扩散出 (v_x,v_y)，积分得到 (x,y)；action 不输出 |
