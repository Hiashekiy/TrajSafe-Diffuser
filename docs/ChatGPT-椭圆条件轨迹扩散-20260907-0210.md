## 最后把这版核心压成一句话

原 V1 是：

$$
\boxed{
\text{所有东西都只看 }16\times16\text{ global map feature}
}
$$

V1.1 改成：

$$
\boxed{
\underbrace{16\times16}_{\text{Global topology}}
+
\underbrace{
16\rightarrow32\rightarrow64\rightarrow32
}_{\text{Decoded fine geometry}}
}
$$

Trajectory 和 Ellipse 继续通过 Joint Attention 共同扩散；Ellipse 额外读取高分辨率 geometry memory，并通过

$$
\boxed{
\bar\alpha_t
}
$$

控制的 spatial bias，从**早期全局搜索逐渐过渡到后期局部几何关注**。

而且整个过程中：

$$
\boxed{\text{不需要 GT trajectory 采样，不需要 hard grid sampling，也不需要第二次预测轨迹。}}
$$

如果你现在就准备改代码，实际只需要重点改 **3 个文件**：

`scene_cnn.py` → Encoder + Decoder + 双 memory 输出；  
`joint_blocks.py` → 增加 GeometryCrossAttention；  
`joint_planner.py` → 构造两套 memory + noise-aware bias。

`train.py` 和 `sampler_v1.py` 第一轮都不要动。
