# Maze2D 混合数据集轨迹动力学一致性验证报告

> 日期：按当前会话生成
> 对象：`data/processed/mixed` 中的轨迹标签
> 方法：读取原始 D4RL HDF5 + 混合数据，通过位置-速度、速度-动作关系反推时间步长并验证动力学一致性。
> 结论：`[ax, ay, x, y, vx, vy]` 轨迹标签在离散控制意义下是自洽的；推得的有效时间步长为 `dt≈0.01`。

---

我查了原始 D4RL HDF5，又对 `data/processed/mixed` 里的轨迹标签做了动力学一致性验证。

## 1. 时间步长从哪来

HDF5 里 **没有 `metadata`/固定 `timestep` 字段**，所以只能从数据本身推断。

我用原始观测 `[x, y, vx, vy]` 和混合后的世界坐标轨迹，看相邻两步位置差和速度的关系：

```
dx ≈ vx * dt
dy ≈ vy * dt
```

结果（`|dx|/|vx|`、`|dy|/|vy|`）：

```text
raw  umaze   : median ≈ 0.0098  ~ 0.0099
raw  medium  : median ≈ 0.0099
raw  large   : median ≈ 0.0099
mixed data   : median ≈ 0.0101 （p25≈0.0090, p75≈0.0112）
|dx| 与 |vx| 相关系数 ≈ 0.98
```

**所以这套数据的有效时间步长是 `dt ≈ 0.01`。**

## 2. 位置-速度关系是否成立

成立且非常干净：

- 相邻位置差 ≈ 速度 × 0.01。
- 混合数据集经过 `scale + 平移` 后仍然保持这个关系（因为位置和速度同时被同一个比例 `s` 缩放）。
- 3 张迷宫一致，说明不是偶然。

## 3. 速度-“动作”/加速度关系

`[ax, ay]` 是 D4RL 的 `actions`（控制输入/力），我验证：

```text
|dv| / |a|  ≈ 0.238   （umaze/medium/large 都一致）
混合后      ≈ 0.238
```

这个 **不是 `dt=0.01`**，而是 `0.238`。

也就是说：

- 如果用 `dt=0.01` 理解动力学，则 `dv/dt ≈ 23.8 * a`。
- 所以 `[ax, ay]` **不是“精确的物理加速度”**，而是带增益的控制输入（力/动作），它和速度变化满足离散控制关系 `v_{t+1} - v_t ≈ 0.238 * a_t`。

这是 D4RL 这类控制任务的常见约定：`actions` 是控制量，不是直接等于加速度。

## 4. 结论

`data/processed/mixed` 里的轨迹标签：

- **位置–速度动力学是自洽的**（`dt≈0.01`）。
- **速度–动作动力学也是自洽的**（`dv ≈ 0.238 * a`，常数跨迷宫一致）。
- 混合数据集在缩放/平移后仍保留这些关系。
- 唯一问题是：**没有显式记录 `dt` 元数据**，它是从数据反推出来的；如果你想严格用 `dt=0.01`，建议在 `configs/config.yaml` 或文档里写清楚，防止以后混淆。

⚠️ 我没有改动任何数据或代码，只做了读取/验证。
