# 2. 新增一：Trajectory Smoothness Loss

你的主要问题是预测轨迹沿着走廊有小幅高频摆动。

对于：

$$
P=[p_0,p_1,\ldots,p_{H-1}]
$$

定义二阶差分：

$$
\boxed{
\Delta^2p_k
=
p_{k+1}-2p_k+p_{k-1}
}
$$

它反映的是轨迹局部方向变化。

如果一段轨迹是直线：

$$
\Delta^2p_k\approx0
$$

如果出现锯齿：

$$
\Delta^2p_k
$$

会明显增大。

你现在 `evaluate.py` 中的 `traj_smoothness` 本身就是根据这个二阶差分计算的。

## 2.1 不直接把二阶差分压成 0

不采用：

$$
L=\|\Delta^2\hat P_0\|
$$

因为 Medium / Large 真正转弯的地方本来就应该：

$$
\Delta^2P_0\neq0.
$$

否则容易把拐角过度拉直。

采用 **GT 二阶差分匹配**。

预测：

$$
\hat a_k
=
\hat p_{k+1}
-
2\hat p_k
+
\hat p_{k-1}
$$

GT：

$$
a_k^*
=
p_{k+1}^*
-
2p_k^*
+
p_{k-1}^*
$$

定义：

$$
\boxed{
L_{\mathrm{smooth}}
=
\frac{1}{H-2}
\sum_{k=1}^{H-2}
\operatorname{SmoothL1}
(
\hat a_k,a_k^*
)
}
$$

这样：

- GT 直线 → 压制预测锯齿；
- GT 转弯 → 保留合理转弯；
- 不会强迫所有路径都变直。

# 7. Soft Ellipse Mask 的具体计算

不需要显式构造：

$$
Q_k
$$

直接把地图点旋转到椭圆坐标系。

地图点：

$$
u=(x,y)
$$

椭圆中心：

$$
c=(c_x,c_y)
$$

先：

$$
d_x=x-c_x
$$

$$
d_y=y-c_y.
$$

旋转：

$$
x'
=
\cos\theta\,d_x
+
\sin\theta\,d_y
$$

$$
y'
=
-\sin\theta\,d_x
+
\cos\theta\,d_y.
$$

归一化二次型：

$$
\boxed{
q(u)
=
\frac{x'^2}{a^2}
+
\frac{y'^2}{b^2}
}
$$

因此：

$$
q<1
$$

在 ellipse 内，

$$
q=1
$$

在边界，

$$
q>1
$$

在外部。

Soft mask：

$$
\boxed{
M(u)
=
\sigma
[
\tau(1-q(u))
]
}
$$

---

# 8. 为什么用 Soft Mask 而不是硬 mask

如果直接：

$$
M(u)=
\begin{cases}
1&q(u)\le1\\
0&q(u)>1
\end{cases}
$$

边界判断不可微。

而 sigmoid：

$$
\sigma[\tau(1-q)]
$$

使椭圆边缘具有连续过渡。

例如：

$$
q\ll1
\Rightarrow
M\approx1
$$

$$
q\gg1
\Rightarrow
M\approx0
$$

$$
q\approx1
\Rightarrow
M
$$

对椭圆参数有明显梯度。

因此障碍与 ellipse 接触的时候，可以直接产生反向传播。

# 11. Safety Loss 我建议稍微修改 Neural-IRIS 的原始写法

Neural-IRIS 原始：

$$
\sum M O
$$

可以用。

但我们这里不同 ellipse 的：

$$
a,b
$$

变化比较大。

如果直接使用全图 mean：

$$
\frac1{R^2}\sum MO
$$

一个很小的 ellipse，即使穿墙比例很严重，其 absolute overlap 也可能很小。

所以我建议做成：

$$
\boxed{
L_{\mathrm{safe}}
=
\frac1{BH}
\sum_{b,k}
\frac{
\sum_u
M_{bk}(u)O_b(u)
}{
\sum_u M_{bk}(u)+\epsilon
}
}
$$

也就是：

$$
\boxed{
\text{Obstacle-overlap area}
/
\text{Ellipse soft area}
}
$$

它仍然完全是 Neural-IRIS 的：

$$
\text{Soft Mask}\times\text{Obstacle}
$$

思想，只是做了面积归一化。

这个值非常容易理解：

如果：

$$
L_{\mathrm{safe}}=0
$$

说明 ellipse 与 obstacle 没有重叠。

如果大约：

$$
0.1
$$

说明 soft ellipse 区域大约有 10% 落在障碍区域。

这样不同尺度 ellipse 更公平。

# 13. 完整的 Ellipse Safety 函数

第一版可以写成：

```python
def ellipse_safety_loss(
    p_pred,
    e_pred,
    occ,
    raster_res=64,
    tau=10.0,
    eps=1e-6,
):
    # --------------------------------
    # 1. ellipse parameters
    # --------------------------------
    center = p_pred + e_pred[..., :2]

    loga = e_pred[..., 2]
    logb = e_pred[..., 3]

    # numerical protection only
    a = torch.exp(torch.clamp(loga, -6.0, 0.7))
    b = torch.exp(torch.clamp(logb, -6.0, 0.7))

    theta = 0.5 * torch.atan2(
        e_pred[..., 5],
        e_pred[..., 4],
    )

    # --------------------------------
    # 2. occupancy 256 -> 64
    # --------------------------------
    occ_r = F.adaptive_max_pool2d(
        occ,
        output_size=(raster_res, raster_res)
    )

    # --------------------------------
    # 3. scene grid [-1,1]^2
    # --------------------------------
    coord = (
        torch.arange(
            raster_res,
            device=occ.device,
            dtype=occ.dtype
        ) + 0.5
    ) * (2.0 / raster_res) - 1.0

    gy, gx = torch.meshgrid(
        coord,
        coord,
        indexing="ij"
    )

    gx = gx[None, None, :, :]
    gy = gy[None, None, :, :]

    # --------------------------------
    # 4. relative coordinates
    # --------------------------------
    cx = center[..., 0, None, None]
    cy = center[..., 1, None, None]

    dx = gx - cx
    dy = gy - cy

    ct = torch.cos(theta)[..., None, None]
    st = torch.sin(theta)[..., None, None]

    xr = ct * dx + st * dy
    yr = -st * dx + ct * dy

    # --------------------------------
    # 5. quadratic form
    # --------------------------------
    a = a[..., None, None]
    b = b[..., None, None]

    q = (
        (xr / a) ** 2
        +
        (yr / b) ** 2
    )

    # --------------------------------
    # 6. Neural-IRIS soft ellipse mask
    # --------------------------------
    mask = torch.sigmoid(
        tau * (1.0 - q)
    )

    # --------------------------------
    # 7. obstacle overlap
    # --------------------------------
    obstacle = occ_r[:, None, 0, :, :]

    intersection = (
        mask * obstacle
    ).sum(dim=(-1, -2))

    ellipse_area = mask.sum(
        dim=(-1, -2)
    )

    collision_ratio = (
        intersection
        /
        (ellipse_area + eps)
    )

    return collision_ratio.mean()
```

没有任何 ellipse point sampling。
