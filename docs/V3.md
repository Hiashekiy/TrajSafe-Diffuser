## 1. 唯一核心定义

只有一个 diffusion state：`P_t`。每个 reverse timestep 都重新执行完整网络：

```
P_t -> P~_0 -> S_m -> s -> c -> E -> P^_0 -> P_{t-1}
```

**没有 commit_t，没有 committed 标记，没有 selected_path / selected_feat 缓存，
没有「tc 之前 / 之后」阶段切换。** Skeleton 每一步重新打分、重新选。

粗解码 `P~_0 = head_p(H_t)` 与最终解码 `P^_0 = head_p(H_t^final)`
**共用同一个 head_p**；只有 `P^_0` 进 DDIM。

## 3. Skeleton 几何的四处修复（§8，已全部落地）

| # | 问题 | 做法 |
|---|---|---|
| 1 | 平行 branch 被 nx.Graph 吞掉 | `expanded_graph()`：每条 branch 变成独立节点，junction - branch - junction |
| 2 | start/goal 只连最近一个 anchor | `visible_anchors()` + super source/sink，连接件长度作为边权，与路径一起 K-shortest |
| 3 | in_cluster_path 有 unsafe fallback | 找不到就返回 None，抛 `UnsafeRouteError` 丢弃候选，绝不 [a,b] 直连 |
| 4 | gamma(s) 沿 128 点弦插值 | 候选拆两份：`candidate_features` 只给网络，`candidate_geometry`（dense cell chain）只给 gamma |

重新预处理后：train `mean_valid` 从 V2 的 1.03 升到 **2.35**；dense 链最长 593 点
（`candidate_geometry_points=1280` 够用）。

## 5. 损失（§29）

```
L = 1.00 L_traj + 0.25 L_coarse + 0.10 L_smooth
  + 0.50 L_topo(CE(m*)) + 0.50 L_align + 0.01 L_gap
  + 1.00 L_safe + 0.05 L_area + 0.01 L_ratio + 0.00 L_inside
```

* `L_align = mean SmoothL1(c_i, p_i^GT)`，**不需要 progress 标签**；
* `L_safe` 沿用整椭圆 occupancy 覆盖率 + 逐轨迹 CVaR，地图外算不安全；
* `L_area = 1 - mean(a b / a_max^2)`，轴长有界所以不会发散；
* 训练日志同时打印 raw loss / weighted loss / **gradient norm**，另加 safe/area 比值，
  方便观察两项是否互相压制。

## 6. 训练时 Skeleton 选择调度（§12）

```yaml
selection_schedule:
  gt_until_epoch: 10        # epoch < 10   : 100% GT (m*)
  predicted_from_epoch: 30  # epoch >= 30  : 100% predicted
                            # 中间线性过渡
```

调度决策发生在拓扑打分之后（要用 pi 的 argmax），因此仍是单次 forward。
推理永远用预测的 m（默认 `argmax`，`--selection sample` 可切 categorical）。

## 7. 测试

```bash
python -m pytest tests/ -q      # 134 passed
```

`tests/test_v3_geometry.py`（8 项）覆盖 §8 四处修复 + gamma 用 dense 链。
`tests/test_v3_model.py` 覆盖 §32 的模型 / 采样器 / 损失行为：

* timestep 经 AdaLN 进入**每一个** denoising block（含 selector / progress / ellipse）
* coarse 与 final 共用同一个 head_p（源码级断言 + 权重扰动验证）
* progress 严格单调、s_1=0、s_H=1
* 无 progress 标签时 L_align 仍有梯度，且**不会**流到 ellipse head
* safety loss 对 a/b/theta 有非零梯度；area loss 会把椭圆推大；两者同时反传正常
* invalid candidate 永不被选中（logits=-inf、pi=0）
* **每个 reverse step 都重新打分**（score_candidates 调用次数 == 步数）
* 源码级断言：采样器 / 模型里不存在 commit_t / committed / 选择缓存
* 子采样 DDIM 末步严格落 P_0 = P^_0（全 schedule 与 --steps 都验证）
* no-candidate 行端到端正常，topo/align/safe/area 全 0 且不产生 NaN
* **不同 P_t 允许选出不同 Skeleton**（刻意**不**断言「同 seed 必须同 Skeleton」）
