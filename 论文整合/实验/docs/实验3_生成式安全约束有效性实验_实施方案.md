# 实验 3：生成式安全约束有效性实验——实施方案

> 项目：TrajSafe-Diffuser  
> 论文定位：验证第 3.2 节“局部椭圆预测—凸区域构造—凸安全走廊”中**学习型椭圆几何先验**的作用。  
> 实验性质：**同一模型的几何输入替换实验**；不新增训练模型或数据集。  
> 实验状态：待实施。本文档中的阈值及基线尺寸均为实施方法，**没有预填未测得的实验结果**。

## 1. 实验目的与需要回答的问题

在 TrajSafe-Diffuser 中，网络以所选骨架通路的自由空间采样点作为局部椭圆中心，预测椭圆的长短半轴及方向，再依据占据地图、边界和安全裕度，通过确定性几何构造得到局部凸区域；必要时加入桥接区域，形成连续凸安全走廊。走廊进一步为逆扩散过程中的 ALM 修正提供约束。

本实验只针对一个问题：**在相同骨架和相同凸区域构造算法下，学习得到的椭圆参数，是否优于固定的简单几何先验？**

验证分为两个相互关联的层面：

1. **凸走廊本身的质量**：构造是否成功、局部凸区域规模如何、是否需要大量额外桥接。
2. **最终规划效果**：使用该走廊执行完整扩散采样与 ALM 修正后，轨迹安全性和绕行程度是否有所变化。

注意：本实验**不单独验证**骨架通路匹配网络，也**不宣称**能隔离学习安全特征 $H_{\mathrm{ell}}$ 的全部贡献。它检验的是**椭圆几何参数作为凸区域构造先验**这一具体设计。

## 2. 三组对照配置

| 配置名称 | 椭圆中心 | 半轴大小 | 方向 | 网络权重 |
|---|---|---|---|---|
| **Fixed Circle** | 已选骨架采样点 $c_i$ | 固定半径 $r_0$，即 $a_i=b_i=r_0$ | 不适用 | 与完整模型相同 |
| **Fixed Ellipse** | 同一骨架采样点 $c_i$ | 固定半轴 $a_0,b_0$ | 骨架局部切向 $\theta_i^{\mathrm{tan}}$ | 与完整模型相同 |
| **Learned Ellipse** | 同一骨架采样点 $c_i$ | 网络预测 $a_i,b_i$ | 网络预测 $\theta_i$ | 与完整模型相同 |

三种配置均使用同一个生成器 **A** 的权重，并保持以下条件一致：

- 占据地图、任务起终点、障碍膨胀与安全边界设置；
- 候选骨架的提取及匹配规则，骨架采样点数（128）；
- 地图特征、骨架特征和局部安全特征 $H_{\mathrm{ell}}$ 的计算；
- 从椭圆先验生成障碍物自由凸区域的确定性算法；
- 相邻区域重叠判据、沿骨架桥接算法、走廊连接判据；
- ALM 优化目标、约束容差、最大迭代次数及失败处理规则；
- DDIM 时间步序列、初始噪声、历史反馈机制和网络参数。

**唯一干预项**：传给凸区域构造模块的椭圆**半轴与朝向**。不得同时修改去噪网络的 $H_{\mathrm{ell}}$、重新训练预测头或改变走廊构造器的搜索预算，否则无法判断差异来自哪里。

### 2.1 固定先验参数的确定方式

固定圆半径 $r_0$ 与固定椭圆半轴 $a_0,b_0$ 必须在**验证集**上确定并冻结，禁止使用测试集进行参数选优。推荐可复现的初始方案：

1. 用现有 A 模型在验证集上运行学习型椭圆预测，收集有效的预测半轴 $a_i,b_i$。
2. 设 $a_0=\operatorname{median}(a_i)$、$b_0=\operatorname{median}(b_i)$；必要时按既有规则排序，使 $a_0\ge b_0$。
3. 设固定圆面积与固定椭圆面积一致，即 $r_0=\sqrt{a_0b_0}$。
4. 固定椭圆的方向按该点附近骨架弧长参数的切向计算。若切向退化，采用预先定义的统一备用方向。
5. 将 $r_0,a_0,b_0$ 与求取它们的验证集、模型 checkpoint 和预测步骤写入配置文件。

这样可以避免任意挑选固定先验尺寸造成不公平。若模型在不同时间步预测的椭圆大小变化明显，可在验证集上按统一采样时刻汇总；无论采用哪种汇总口径，三组测试前必须固定，不得根据测试效果调整。

### 2.2 实验前必须确认的实现事实

**先做一个很小的功能验证，不要直接运行 1260 条完整采样。**

在同一地图、同一骨架、同一去噪状态下，依次输入三种椭圆参数，导出：

- 原始椭圆参数及位置；
- 每个骨架锚点最终构造出的凸多边形顶点或半空间约束 $(A_i,b_i)$；
- 桥接后的完整区域列表。

检查三组参数是否**真的导致凸区域几何发生变化**。如果构造器最后完全依赖障碍物与骨架中心、把椭圆信息丢弃，那么三组结果可能几乎相同；此时应先核实原方法实现，而不能把“替换了预测头输出”当成有效消融。

还应确认凸区域的安全性检查使用相同坐标系、栅格分辨率和膨胀规则。

## 3. 数据集、样本配对和运行配置

| 项目 | 统一设置 |
|---|---|
| 数据来源 | 现有 CARLA 二维静态占据栅格测试集 |
| 测试任务数 | 420 |
| 随机种子 | 0、1、2 |
| 每组最终规划次数 | $420\times3=1260$ |
| 三组总规划次数 | $1260\times3=3780$ |
| 生成器 | A：安全条件与反馈训练生成器，**相同 checkpoint** |
| 轨迹表示 | $C=48$ 个控制点的三次 B 样条 |
| 标准推理 | 16 步 DDIM；前 3 次前向预热，之后按既定规则启用 ALM |
| ALM 预算 | 首次最多 8 次内部迭代，后续最多 10 次（与既有实验一致） |
| 障碍物设置 | 沿用实验 1 的地图、膨胀和边界设置 |
| 日志单位 | 位置、距离：m；多边形面积：$\mathrm{m}^2$；时间步、区域数：无量纲 |

三组使用完全相同的 `(sample_id, seed)` 配对，复用同一份初始高斯噪声。**不能因为某种方法失败，就把该任务从其他组中删除。**

需要区分两个层面的“相同骨架”：

- **局部几何对照**：给三组构造器输入完全相同的已选骨架及其 128 个中心点，以便直接比较椭圆先验造成的几何差异。
- **完整采样对照**：三组的网络权重、初始噪声和骨架选择算法相同，但由于 ALM 修正会影响后续 DDIM 状态与反馈，后续时间步实际选出的骨架可能发生变化。这属于干预的下游效应，不应在论文中错误地声称所有步骤的骨架始终相同。

为避免混淆，建议同时记录每一步的 `selected_route_id`、骨架中心序列及对应椭圆配置；局部走廊指标可以使用相同输入状态的配对快照，最终轨迹指标则使用各自真实的完整推理结果。

## 4. 实施流程

### 4.1 阶段 A：局部凸安全走廊构造比较

目的：隔离“椭圆先验 → 凸多边形/走廊”这个环节，避免后续扩散状态不同造成难以解释的差异。

1. 从现有测试任务中抽取同一个模型状态下的**已选骨架**、128 个骨架中心和局部地图信息；推荐使用标准采样流程中第一次真正启用安全修正的时间步作为统一快照位置。
2. 针对这份完全相同的输入，分别生成 Fixed Circle、Fixed Ellipse、Learned Ellipse 三套几何参数。
3. 逐套调用相同凸区域构造算法；记录各锚点局部区域是否有效、面积与区域数量。
4. 使用相同的重叠阈值和沿骨架桥接策略，得到最终凸安全走廊。
5. 按相同的定义检查走廊连通与起终点覆盖，记录成功或失败，以及新增桥接区域数。
6. 对所有输入快照按相同统计口径汇总三组结果。

备注：阶段 A 是**实验 3 的诊断步骤**，不是另加一项独立实验。其结果对应“安全走廊构建成功率、局部区域面积和桥接数”。

### 4.2 阶段 B：完整扩散规划比较

目的：验证不同几何先验经由凸安全走廊与 ALM 后，对最终轨迹的实际影响。

1. 固定模型 A 的权重和测试输入，重置当前 `(sample_id, seed)` 的初始噪声。
2. 按选定几何配置正常执行 16 步 DDIM。
3. 对每个启用几何修正的步骤，只替换传给凸区域构造器的椭圆参数，其余处理链路保持不变。
4. 沿用原算法完成局部凸区域构造、相邻区域桥接、B 样条分段 Bézier 转换、ALM 修正、DDIM 更新与历史反馈。
5. 保存最终 B 样条控制点及轨迹；统一计算碰撞率和路径绕行系数。
6. 原样记录走廊生成失败、ALM 不满足接纳条件、轨迹未生成等事件，不得跳过失败样本。
7. 对 420 个任务与三个种子分别运行三组，按相同样本编号汇总配对结果。

若某组走廊构造失败，原则上记为该次规划**未成功完成**，不能默默切换为另一套先验或只报告成功子集；若代码已有统一安全降级策略，则三组必须启用同一策略并明确记录发生次数。

## 5. 五项评价指标及精确定义

这里保持已确定的**五项指标**，不另增测试项目。

### 5.1 安全走廊构建成功率（Corridor Construction Success Rate，%）↑

对阶段 A 每份输入快照，要求：

1. 构造区域全部经过现有的地图/障碍自由空间有效性检查；
2. 相邻区域经重叠或有效桥接形成连续的区域序列；
3. 走廊对所要求的通路两端具有有效覆盖；
4. 无无法消除的断连或区域构造异常。

记成功指示量为 $I_n^{\mathrm{corr}}\in\{0,1\}$，则

$$
\mathrm{CSR}=\frac{1}{N}\sum_{n=1}^N I_n^{\mathrm{corr}}\times100\%.
$$

分母 $N$ 为**全部预先确定的快照**，包括构造失败项。连接判据应与正式规划使用的判据保持一致，不要为统计指标重新设置一套更宽松的重叠阈值。

### 5.2 平均基础凸区域面积（Mean Base Convex Region Area，$\mathrm{m}^2$）

为了避免“桥接数量不同”干扰区域面积比较，只统计从原有 128 个骨架中心生成的**基础区域**，桥接区域不混入该指标：

$$
\overline A=\frac{\sum_{n\in\mathcal S}\sum_{i\in\mathcal I_n} \operatorname{Area}(\mathcal R_{n,i})}{\sum_{n\in\mathcal S}|\mathcal I_n|}.
$$

其中 $\mathcal S$ 表示走廊构造成功的快照集合，$\mathcal I_n$ 为其中有效的基础区域编号。面积由真实凸多边形顶点按地图物理尺度计算，不使用椭圆面积代替最终凸区域面积。

**解释限制**：面积大不等于规划性能一定好；同时报告走廊成功率及轨迹质量，避免单独用面积评价优劣。若存在大量失败项，必须同时列出每组成功样本数，不能只展示成功部分的平均面积。

### 5.3 平均桥接区域数量（Mean Number of Bridge Regions，个/任务）↓

记第 $n$ 个成功快照中，为连接原有凸区域而**额外构造并纳入有效走廊**的桥接多边形数量为 $B_n$，则

$$
\overline B=\frac{1}{|\mathcal S|}\sum_{n\in\mathcal S} B_n.
$$

这项指标反映原始区域序列的连通程度以及对额外桥接的依赖，而不是直接代表运行时间。失败快照单独计入走廊构建成功率，不将其桥接数量强制记为零。

### 5.4 最终轨迹碰撞率（Collision Rate，%）↓

阶段 B 采用与实验 1 **完全相同**的碰撞检查方式（沿连续轨迹等参数采样 512 点；坐标、障碍物膨胀和边界处理规则一致）。

$$
\mathrm{CR}=\frac{N_{\mathrm{collided}}}{N_{\mathrm{generated}}}\times100\%.
$$

其中 $N_{\mathrm{generated}}$ 是该组**实际成功生成、可进行碰撞检查的轨迹数**，$N_{\mathrm{collided}}$ 是其中至少一个采样点与障碍相交的轨迹数。

**必须同时给出 $N_{\mathrm{generated}}/1260$。** 走廊失败、求解失败和未输出轨迹均不应被误算为“无碰撞”；如果某组只在少量任务中成功生成，单独的碰撞率不足以表明它更安全。

### 5.5 路径绕行系数（Detour Ratio，无量纲）↓

沿用实验 1 已确定的定义，对成功生成轨迹计算：

$$
R_L^{(n)}=\frac{L\bigl(\tau_{Q^{(n)}}\bigr)}{\|G_n-S_n\|_2},
\qquad
\overline R_L=\frac{1}{N_{\mathrm{valid}}}\sum_{n\in\mathcal V}R_L^{(n)}.
$$

轨迹长度应按一致的弧长数值积分或足够密的固定采样策略求得；禁止直接用 B 样条控制点连线长度代替曲线长度。对 $\|G_n-S_n\|_2$ 近零的退化任务按统一预设规则排除。

推荐主报告口径：**无碰撞且成功生成的轨迹**上的平均绕行系数，同时注明有效样本数；这样不会把穿越障碍获得的短路径视为更高质量的规划。若成功率各组差异很大，文字中须指出条件统计的局限。

## 6. 推理程序的最小修改建议

不修改训练流程、不修改网络结构。新增一个与现有几何模块适配的模式开关，例如：

```yaml
experiment: generative_safety_geometry
ellipse_prior_mode: learned   # learned | fixed_circle | fixed_ellipse
fixed_prior:
  radius_m: null             # 从验证集确定后填写
  semi_major_m: null
  semi_minor_m: null
  direction: skeleton_tangent
model_checkpoint: null       # 填写同一生成器 A 权重
num_ddim_steps: 16
seeds: [0, 1, 2]
```

伪代码：

```python
# 原始网络前向保持不变，H_ell 继续用于条件去噪
H_ell, ellipse_pred = predict_safety_geometry(...)

if ellipse_prior_mode == "learned":
    ellipse_for_region = ellipse_pred
elif ellipse_prior_mode == "fixed_circle":
    ellipse_for_region = make_fixed_circles(
        centers=selected_skeleton_centers, radius=radius_m)
elif ellipse_prior_mode == "fixed_ellipse":
    ellipse_for_region = make_fixed_ellipses(
        centers=selected_skeleton_centers,
        a=semi_major_m, b=semi_minor_m,
        theta=skeleton_tangent_angles)

regions = construct_convex_regions(
    occupancy_map, ellipse_for_region, same_margin_and_budget)
corridor = connect_regions_with_bridges(regions, same_rules)
# 接下来保持原始 ALM、DDIM 与历史反馈逻辑
```

注：以上仅为插入点示意，并非仓库中的实际函数名。**需要先找到真实的“预测椭圆 → 构造凸区域”接口再实现**，避免替换到了一个不参与后续计算的变量。

2. 结合基础区域面积和桥接数量，讨论差异具体体现在哪里。
3. 结合最终碰撞率和绕行系数，判断几何构造差异是否传导到规划结果。
4. 如果三组最终安全性都很高，明确说明 ALM 的安全兜底作用；不要因为学习椭圆在某一个指标上领先，就声称它单独保证了安全。
5. 如结果差异很小，应据实说明可能是确定性凸区域构造或 ALM 主导了最终表现，并据此谨慎调整论文贡献表述。

## 10. 最小实施顺序

1. **代码审查**：确认椭圆几何参数确实参与最终凸区域构造。
2. **验证集定参**：得到并冻结 $r_0,a_0,b_0$。
3. **单样本调试**：三种先验输出椭圆、凸多边形及走廊，排查坐标或尺度错误。
4. **小批量核验**：例如 10 个任务、每个任务 3 种模式，确认失败记录和评价逻辑无误。
5. **全量局部几何评价**：采集相同输入状态的配对快照，统计走廊成功率、基础区域面积和桥接数。
6. **全量规划评价**：运行 3 种模式 × 420 个任务 × 3 个种子，统计有效输出、碰撞率和绕行系数。
7. **汇总论文图表**：一张结果表、一张三列几何可视化图。
