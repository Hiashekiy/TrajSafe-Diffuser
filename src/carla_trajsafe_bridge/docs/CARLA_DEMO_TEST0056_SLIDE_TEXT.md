## 二、效果说明（效果块）

### guided（ALM 开）

- 规划轨迹 69.2 m，最大曲率 0.652 1/m，远低于自车极限 1.040 1/m；
- **0/128 采样点越出可行驶区**，车身四角在可行驶区内的比例 99.35%；
- 对停放车的最小车身间隙 2.07 m，凸走廊贴合率 99.4%，10 项硬验收全过；
- 闭环实车：34.6 s 到达终点，**终点误差 0.44 m**，横向误差 RMS 0.28 m / 最大 0.61 m，**0 碰撞**。

### raw（ALM 关，同 checkpoint / seed / 控制器）

- 规划轨迹只有 59.2 m，**53/128 = 41.4% 的采样点越出可行驶区，最深 4.70 m**；
- 对停放车的车身间隙降到 **0.00 m**（轨迹直接压在障碍上）；
- 闭环实车：切进路侧广场，**与停放车碰撞 6 次**，停在终点前 17.8 m，未能到达。

### 结论

- 关掉 ALM 后，扩散模型只按数据分布采样，在"窄路 + 急弯 + 贴边障碍"的几何下会直接切角穿越非行驶区；
  ALM 用**冻结凸走廊**在控制点空间逐步做增广拉格朗日校正，把采样结果拉回安全走廊内；
- 因此安全引导不是后处理美化，而是这条 pipeline 在真实道路几何下**能否走通的决定性环节**。

## 三、图怎么看（给听众的读图说明）

- 绿色 = 可行驶区，红色 = 路缘 / 草地 / 建筑（由占据图直接投影到相机画面，像素级对齐）；

## 四、口播稿（约 220 字）

这一页是生成效果的展示。实验配置是：CARLA Town03 同步仿真，取数据集样本 test_0056，
自车按记录位姿初始化，终点设在支路里，支路中停一辆静态车作为障碍，并且按自车尺寸膨胀后
写进占据图；然后**只规划一次**，之后全程只做跟踪。两组实验唯一的区别就是 ALM 开关，
其余 checkpoint、随机种子、占据图、控制器完全相同。

左边 guided 组：画面里绿色是可行驶区、红色是路缘草地，我们把占据图和生成轨迹直接投到相机上。
轨迹全程没有越出可行驶区，实车 34.6 秒到达终点，误差 0.44 米，零碰撞。

右边 raw 组：同样条件下，41% 的规划采样点越出了可行驶区，最深 4.7 米；
实车切进路侧广场，撞上停放的车辆六次，停在终点前 17.8 米。
这说明 ALM 的安全引导不是锦上添花，而是这条 pipeline 能不能走通的关键。

## 五、可能被问到的问题

**Q：raw 的轨迹为什么进草地？**
A：扩散模型只学数据分布，采样时没有几何约束；窄路急弯处最短路径会切角，
在没有 ALM 校正时就直接穿过路缘。

**Q：那辆障碍车哪来的？**
A：数据集采集时没有 NPC，为构造避障场景人为添加的静态障碍，
按 0.20 m 膨胀写入占据图后才做规划，属于实验设置的一部分。

**Q：70 度前轮角是不是太大了？**
A：这是 CARLA 仿真器给出的车辆运动学参数（WheelPhysicsControl.max_steer_angle），
乘用车实际一般在 35–40 度；这里只用来说明"规划曲率在仿真车辆能力范围内"。

**Q：为什么只规划一次？**
A：guided ALM 单次采样约 1.8 s，适合"停车规划 + 闭环跟踪"；
在线重规划在计划文档里列为第二阶段工作。
