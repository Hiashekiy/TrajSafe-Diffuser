# 最终性能对比表（统一 1.25 m 余量，test 全量 420 场景，2026-11-14）

**协议**：test split 全部 **420 场景**；同一基座（`safety_points_t256/ckpt/best.pt`，5.3958 M，
epoch 41）；seed 0；七行共用同一条官方级阶梯（`reversed(range(-64,256))`，t=1 重访且不加噪）
与同一个初始噪声（`initial_seed` 配对协议）；评价器 `unified_curve_eval`（512 点曲线 + 弧长均匀
违规占比）。原始数据 `results/final_m2/b{0,1,2}/results.jsonl`（2940 行，**0 重复**）。

**这一版与前几版唯一的区别：所有方法统一给 2 个栅格的余量。**
2 格 = `0.015625` 场景单位 = **1.25 m**（1 格 = 2.0/256 = 0.0078125 场景单位 = 0.625 m）。落到配置上是
四个覆盖，对七行同时生效：

| 字段 | 值 | 作用对象 |
|---|---|---|
| `radius_scene` | 0.015625 | 六种点约束方法（障碍集整体膨胀） |
| `segment_circle_margin_scene` | 0.015625 | PDM（圆半径加余量） |
| `sd_tvs_level_scene` | 0.015625 | TVS（时变水平项也按 2 格，否则它会偷偷多拿 10 m） |
| `dual_eta` | 6.1035e-09 | Primal-Dual（标定过的 η/10） |

基线 `Diffuser-ddpm` 不受余量影响，直接复用同一批 420 场景的既有结果。

## 2. 余量到底贡献了多少（同一批 420 场景，前后对照）

| 方法 | 零余量 | **1.25 m 余量** | 变化 |
|---|---:|---:|---|
| 无修正基线 | 49.5% | — | 与余量无关 |
| RoS | 39.0% | **14.8%** | 碰撞 −24.2 pt（2.6×） |
| ReS | 39.5% | **15.0%** | −24.5 pt（2.6×） |
| TVS | 3.6% | **11.7%** | **变差 +8.1 pt**（见 §3） |
| Projected | 32.6% | **8.3%** | −24.3 pt（3.9×） |
| Primal-Dual | 49.3% | **41.0%** | −8.3 pt |
| ALM | 30.0% | **23.6%** | −6.4 pt |
| PDM | 1.2% | **0.0%** | −1.2 pt（且 0 撞墙） |

**余量是这七个方法里最强的单一杠杆**，比换算法本身影响还大：RoS/ReS/Projected 都靠它把碰撞率
砍掉 2.6–3.9 倍，而它们各自的算法差异在零余量时只有 6–16 个百分点。

## 3. TVS 那一行的真相：它的优势本来就是余量

零余量版里 TVS 是 3.6%、远好于 RoS 的 39.0%，看上去"TVS 算法更强"。但 TVS 的时变水平项
自带 **`sd_tvs_level_scene=0.125 = 16 格 = 10 m` 的额外余量**——它不是没有余量，而是余量最大。

把它的余量统一到 2 格（1.25 m）后：**TVS 11.7%，与 RoS 14.8% / ReS 15.0% 同档。**
即"TVS 的算法优势"在余量对齐后基本消失，这与 `official_test420_table.md` §2 的余量敏感性
（0.05→11.7%、0.125→3.6%、0.25→10.5%）完全一致：**那个 3.6% 是 10 m 余量买来的。**

## 4. 四条结论

1. **统一余量后排名**：PDM 0.0% < Projected 8.3% < TVS 11.7% ≈ RoS 14.8% ≈ ReS 15.0%
   < ALM 23.6% < Primal-Dual 41.0% < 基线 49.5%。
2. **只有 PDM 与 Projected 是"机制上"有效**：PDM 用段约束 + 每级精确投影（0 撞墙）；
   Projected 每步把点投影回可行集边界（8.3%）。两者都是**投影**，不是乘子。
3. **乘子法（PD / ALM）最弱**：同样的余量下仍是 41.0% / 23.6%。它们的修正加在后验均值上、
   靠 λ 累积，收敛到"接近边界"而不是"落进可行区"。PD 额外还有 η 的量纲问题（§`pd_why_no_effect.md`）。
4. **形状代价仍然存在**：PDM 长度比 2.79、Projected 1.31、ALM 1.68，而 RoS/ReS/TVS 都在 1.10 附近。
   "碰撞率最低"与"形状最好"不能同时要，表格必须两列并报。
