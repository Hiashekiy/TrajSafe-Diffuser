# 七算法正式比较前的噪声协议选择

## 已有证据

1. 七个完整采样分支、统一逐案例记录/失败处理、独立地图评价、CBF QP和投影已实现。S0共36项通过。最初直接在92维内部控制点上施加128个点约束导致CBF不可行；该试验保留为superseded。固定基函数的物理轨迹状态适配已使七个分支在验证案例上全部完整返回，不改变网络权重或控制点边际先验。
2. 解析状态适配：y=(q,z)，q为46×2内部控制点，z为80×2已知零均值残差，clean z=0。P=offset+[Bint,N]y，N与Bint正交。正确score按固定线性映射的逆转置变换；谱界给出固定单位归一化。最终统一端点固定LS拟合回48控制点，不加安全兜底。因此原生点轨迹满足约束，不保证拟合后B样条安全；两者分别记录。
3. 当前16级cosine训练噪声中，最低训练级别每个控制点坐标的噪声标准差为8.715m；256级为1.099m。这是加噪状态的逐坐标标准差，不是路径RMSE、误差下界，也不证明重训一定成功。DDIM最后直接输出clean预测，而论文Langevin循环末级仍有噪声；当前粗噪声模型使有限采样和B样条拟合的任务适配明显受限。不能在最低训练噪声以下凭空假造score。
4. 本次PDM已纠正为T10/M100；Constrained Diffusers已准备64层更新预算+64额外更新，16级模型会重复合法层；这属于明示的任务适配。若改用256级模型，可从256个已训练的层中选64个合法层，减少重复同一粗级别的问题。仍需重新做S0/S1；不能承诺成功率。
