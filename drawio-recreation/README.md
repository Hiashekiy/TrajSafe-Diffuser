# 特征融合与安全轨迹去噪流程图

使用 diagrams.net / draw.io 打开同目录的 `.drawio` 文件。所有模块、文字、连线和缩略图均为原生可编辑矢量元素，未嵌入参考截图。地图和轨迹缩略图是按参考图重绘的示意占位图。

## 小图重绘版

已按用户给出的语义重新绘制并替换 10 个缩略图位置。主文件与 `-小图重绘版.drawio` 内容相同，`-替换前备份.drawio` 保存旧版本。

- 所有变体共用同一底图和起终点，等比缩放并居中放入原有边框。
- 占据地图只有障碍物和自由空间，无车辆、路径或端点标记。
- 含噪控制点用 17 个代表性离散点与虚线控制多边形表达，不代表实验配置中的真实点数。
- 历史反馈只有修正前后两组对应点、控制多边形和少量修正箭头，无多轮历史轨迹。
- 三条候选分别经过左、中、右通道；选中路线直接复用中间候选的几何数据。
- 走廊由 51 个衔接重叠的椭圆内接凸多边形示意组成，无模糊光晕。最终轨迹缩略图同步采用一致的路线与走廊。
- 小图在 draw.io 中分组，取消组合后可分别编辑障碍物、控制点、线和凸区域；没有栅格图片嵌入。

`thumbnails/` 包含独立 SVG/PNG、8 图总览 `contact-sheet.png`、几何数据和检查记录。独立小图内部不含标题、文字或边框，总览中的标题仅用于素材对照。

执行 `python redraw_thumbnails.py` 可从旧版备份重新生成矢量图和素材。最终交付的整图 SVG 和 `-实际渲染.png` 使用本机 draw.io 原生导出，并检查整图视觉。再次运行生成脚本后需重新执行 draw.io 导出。

这些几何是按用户提示绘制的算法示意，并非规划器实验输出。采样碰撞检查和区域连续性检查仅用于发现绘图错误，不构成算法安全证明。没有声称本次重新核对了 GitHub 代码。
